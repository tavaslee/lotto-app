# 圖片管理功能驗證紀錄

驗證日期：2026-07-23

## Google Drive 連線

Google Drive API 已在既有 Google Cloud 專案啟用。網站現有服務帳號可只讀存取五個指定版路資料夾，資料夾名稱均唯一且與五個彩別一對一對應。

五個資料夾第一層目前均為空白。驗證只執行資料夾可見性、第一層檔案摘要與鏡像預覽，**未呼叫套用同步，也未修改或刪除 Google Drive／網站圖片**。真實服務層預覽均為新增 0、更新 0、略過 0；待刪除數依序為大樂透 1、威力彩 2、今彩 539 共 6、六合彩 1、加州天天樂 6，並均產生 64 字元防過期指紋。

完全鏡像以指定 Drive 資料夾作為該彩別的唯一圖片來源；既有本機上傳、外部網址與舊鏡像圖片若不在資料夾第一層，均會列入刪除預覽。管理介面會先顯示新增、更新與刪除數，再要求管理員確認；Drive 內容或網站圖片於預覽後若發生變更，套用端會以指紋不一致拒絕過期計畫。

## 後台手機版畫面

以 390×844 視窗擷取 `/admin?section=images` 完整頁面。畫面可正常顯示五張輪播圖片、一張大樂透版路圖片、Google Drive 完全鏡像卡、本機多圖上傳、外部網址、多選及批次刪除控制；未觀察到水平溢位、控制項重疊或文字被截斷。

輪播與版路圖片卡均顯示拖曳把手。桌機使用滑鼠拖曳；觸控裝置使用 280 毫秒長按後拖曳，並保留鍵盤排序感測器作為無障礙操作方式。

## 非破壞性原則

本輪驗證沒有點擊批次刪除、排序儲存或 Drive 套用同步。所有會改動正式資料的流程由 Vitest mock／純函式測試覆蓋；真實資料只進行讀取、預覽與畫面呈現驗證。
